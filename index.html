The Needleman–Wunsch Algorithm is one of the most fundamental techniques in bioinformatics, used for global sequence alignment. It compares two DNA sequences from beginning to end and finds the best possible alignment using dynamic programming.

This webpage provides an interactive, step-by-step visual demonstration of how the algorithm works:

  • You can enter two DNA sequences of your choice.
  • The system constructs the full DP (Dynamic Programming) matrix, showing how scores are computed.
  • It highlights each cell as it is filled, explaining whether the algorithm chose a match, mismatch, or gap penalty.
  • The backtracking process is shown visually, helping you understand how the final alignment is reconstructed.
  • Finally, the optimal global alignment is displayed exactly as the algorithm computes it.

Algorithm & C Implementation

Needleman–Wunsch

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MATCH 1
#define MISMATCH -1
#define GAP -2


static inline int max3(int a, int b, int c) {
    int m = (a > b) ? a : b;
    return (m > c) ? m : c;
}

int main() {
    char seq1[200], seq2[200];
    printf("Enter Sequence 1: ");
    scanf("%s", seq1);
    printf("Enter Sequence 2: ");
    scanf("%s", seq2);

    int m = strlen(seq1);
    int n = strlen(seq2);

    
    int dp[m+1][n+1];

    
    for (int i = 0; i <= m; i++) dp[i][0] = i * GAP;
    for (int j = 0; j <= n; j++) dp[0][j] = j * GAP;

    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {

            int scoreDiag = dp[i-1][j-1] + 
                ((seq1[i-1] == seq2[j-1]) ? MATCH : MISMATCH);

            int scoreUp   = dp[i-1][j] + GAP;   // gap in seq2
            int scoreLeft = dp[i][j-1] + GAP;   // gap in seq1

            int chosen = max3(scoreDiag, scoreUp, scoreLeft);

            dp[i][j] = chosen;
        }
    }

    
    printf("\nDP MATRIX:\n\n   ");
    for (int j = 0; j < n; j++) printf("   %c", seq2[j]);
    printf("\n");

    for (int i = 0; i <= m; i++) {
        if (i == 0) printf(" ");
        else printf("%c", seq1[i-1]);

        for (int j = 0; j <= n; j++)
            printf(" %3d", dp[i][j]);

        printf("\n");
    }

    
    int i = m, j = n;
    char align1[m+n+1], align2[m+n+1];
    int k = 0;

    while (i > 0 || j > 0) {

        
        if (i > 0 && j > 0 &&
            dp[i][j] ==
            dp[i-1][j-1] +
            (seq1[i-1] == seq2[j-1] ? MATCH : MISMATCH)) 
        {
            align1[k] = seq1[i-1];
            align2[k] = seq2[j-1];
            i--; 
            j--;
            k++;
        }

        
        else if (i > 0 &&
                 dp[i][j] == dp[i-1][j] + GAP) 
        {
            align1[k] = seq1[i-1];
            align2[k] = '-';
            i--;
            k++;
        }

        
        else {
            align1[k] = '-';
            align2[k] = seq2[j-1];
            j--;
            k++;
        }
    }

    align1[k] = '\0';
    align2[k] = '\0';


    for (int a = 0; a < k/2; a++) {
        char t = align1[a];
        align1[a] = align1[k-1-a];
        align1[k-1-a] = t;

        t = align2[a];
        align2[a] = align2[k-1-a];
        align2[k-1-a] = t;
    }

    printf("\nOptimal Alignment:\n");
    printf("%s\n", align1);
    printf("%s\n", align2);

    return 0;
}
