Welcome to the Needleman-Wunsch Sequence Alignment Visualizer. This project helps you understand DNA sequence alignment and how the Needleman-Wunsch algorithm works.

DNA Basics

DNA (Deoxyribonucleic Acid) is made of four nucleotides: Adenine (A), Thymine (T), Guanine (G), and Cytosine (C). A pairs with T, and G pairs with C. DNA sequences are represented as strings of these letters.

Sequence Alignment Basics

Sequence alignment is the process of arranging DNA sequences to identify regions of similarity. It helps identify mutations, evolutionary relationships, and functional regions. Global alignment aligns entire sequences, while local alignment finds the best matching region.

Algorithm & C Implementation

Needleman-Wunsch Algorithm

The Needleman-Wunsch algorithm performs global sequence alignment using dynamic programming. It initializes a DP table with gap penalties, fills it using match/mismatch and gap scoring, and backtracks to find the optimal alignment.

C Implementation

#include <stdio.h>
#include <string.h>

#define MATCH 1
#define MISMATCH -1
#define GAP -2

int max(int a, int b, int c) {
    int m = (a > b) ? a : b;
    return (m > c) ? m : c;
}

void needlemanWunsch(char *seq1, char *seq2) {
    int m = strlen(seq1);
    int n = strlen(seq2);
    int dp[m+1][n+1];

    for(int i=0;i<=m;i++) dp[i][0] = i*GAP;
    for(int j=0;j<=n;j++) dp[0][j] = j*GAP;

    for(int i=1;i<=m;i++){
        for(int j=1;j<=n;j++){
            int scoreDiag = dp[i-1][j-1] + ((seq1[i-1]==seq2[j-1]) ? MATCH : MISMATCH);
            int scoreUp = dp[i-1][j] + GAP;
            int scoreLeft = dp[i][j-1] + GAP;
            dp[i][j] = max(scoreDiag, scoreUp, scoreLeft);
        }
    }

    int i=m, j=n;
    char align1[2*m], align2[2*m]; 
    int k = 0;
    while(i>0 || j>0){
        if(i>0 && j>0 && dp[i][j]==dp[i-1][j-1]+((seq1[i-1]==seq2[j-1])?MATCH:MISMATCH)){
            align1[k]=seq1[i-1]; align2[k]=seq2[j-1]; i--; j--; k++;
        } else if(i>0 && dp[i][j]==dp[i-1][j]+GAP){
            align1[k]=seq1[i-1]; align2[k]='-'; i--; k++;
        } else{
            align1[k]='-'; align2[k]=seq2[j-1]; j--; k++;
        }
    }
    align1[k]='\0'; align2[k]='\0';
    for(int x=k-1;x>=0;x--) printf("%c", align1[x]);
    printf("\n");
    for(int x=k-1;x>=0;x--) printf("%c", align2[x]);
}
